報價單配對積分制度

系統將使用所有報價單的關鍵字評分與該列商品的 [Type] 與 [中文品名] 的關聯度，計算匹配積分並由最高分者勝出：

評分項目 觸發條件 積分計算公式
Type欄位完全相符 來源 Type 欄位與模板關鍵字完全一致（不分大小寫） 1000 + (長度 × 10) 分
欄位單詞吻合 來源 Type 包含該關鍵字單詞（如 COOLING JACKET 對到 JACKET） 500 + (長度 × 10) 分
中文品名完全相符 商品 中文品名 與模板關鍵字完全一致 800 + (長度 × 10) 分
中文品名 / 全文包含關鍵字 中文品名 或全文中包含該關鍵字 100 + (長度 × 10) 分
  • 勝出規則：比較所有報價單模板後，由最高分者勝出；若所有模板積分皆為 0 分，則標記為 UNMATCHED（未分類品項），記錄於統計卡片並自動略過產檔。

圖片配對評分制度

系統會比對選取的圖片資料夾路徑與內部檔名，計算匹配分數來找出最符合該商品的圖片資料夾：

評分項目 條件說明 增加積分
1. Type 報價單關鍵字匹配 資料夾路徑包含該報價單模板設定的關鍵字 +30 分
2. 細分 Type 款式匹配 資料夾路徑符合來源 Type 拆解出的款式詞（如 APRON, VEST, TOWEL），用來區分同系列下的不同款式資料夾 +45 分
3. Collection 系列匹配 資料夾名稱完全吻合來源 Collection +60 分
資料夾名稱包含來源 Collection +40 分
資料夾內有任一圖片檔名包含來源 Collection（資料夾未命名系列時的容錯） +25 分
4. 顏色匹配加分 資料夾名稱完全吻合來源 中文顏色 +40 分
資料夾內有圖片檔名包含 中文顏色 +30 分
（備用）資料夾名稱包含來源英文 Color 欄位文字 +35 分
5. 尺寸加分 資料夾內有圖片檔名符合該商品的尺寸（如 S、M、L） +15 分
6. 品名關鍵詞加分 資料夾內圖片檔名包含品名拆解後的關鍵詞（2 字以上） 每個詞 +15 分
  • 選取規則：所有資料夾依總分由高到低排序，最高分者即為該商品的圖片來源資料夾。

主圖與情境圖選取命名規範

系統採嚴格專屬檔名比對，恪守「寧可空白，也不要抓錯」原則，只抓取符合下列關鍵字的圖片：

圖檔類型 判定命名規則（只要符合即抓取）
商品正面主圖 檔名包含 主圖、main 或 主圖1（如 主圖.jpg、main.jpg）
情境圖 1 檔名包含 情境圖 1、情境圖1、情境1、scene1 或 1（如 情境圖1.jpg、1.jpg）
情境圖 2 檔名包含 情境圖 2、情境圖2、情境2、scene2 或 2（如 情境圖2.jpg、2.jpg）
  • 選取規則：僅抓取符合專屬命名規則的圖檔，若目錄內未找到符合條件之圖檔則嚴格保持留空，絕不抓取其他圖片或背標冒充。

中文背標配對評分制度

背標配對以「尺寸」為基本門檻。若圖片檔名沒有對到該商品的尺寸，分數直接為 0 分（避免抓錯其他尺寸的背標）：

1. 尺寸評分（基本門檻，未通過則 0 分）

尺寸類型 符合條件與檔名範例 基礎分數
有具體尺寸
(如 M, L, 35-1.0, 110-1.2)		 標準命名：檔名如 背標_M.jpg、背標_35-1.0.png、背標-S.jpg 110 分
檔名包含獨立尺寸：如 _L_、[L]、-L-、L_背標、L.jpg（避免 S 誤判為 XS） 100 分
包含規格數字：去除 cm/mm 等符號後的長寬/厚度數字吻合 90 分
單一尺寸
(UNISIZE, 單一尺寸, ONE)		 檔名包含 單一尺寸、UNISIZE、ONE，或為 背標_ONE / 背標_單一尺寸 100 分
檔名只有寫 背標 或 LABEL 80 分
未填寫尺寸商品
(Excel 沒填尺寸欄位)		 檔名包含 背標 或 LABEL，且沒有標註其他具體尺寸（無 S/M/L 或數字規格） 90 分

2. 品名與特徵加分（通過尺寸門檻後累加）

加分項目 觸發條件 增加積分
中文品名完全吻合 檔名包含該商品的完整中文品名 +50 分
品名關鍵詞吻合 檔名包含品名拆解後的關鍵詞（如「圍裙」、「附繩款」等） 每個詞 +25 分
中文顏色吻合 檔名包含商品的 中文顏色（紅色不會誤對到粉紅色） +30 分
Collection 系列名稱吻合 檔名包含商品的中文或英文 Collection +20 / +15 分

3. 搜尋與合格標準

  • 商品資料夾搜尋：在該商品的圖片資料夾中尋找，分數最高且 總分 ≥ 90 分 者採用。
  • 未找到則留空：若該商品資料夾內沒有 ≥ 90 分的背標圖檔，依「寧可空白，也不要抓錯」原則直接保持空白，避免放錯背標。

圖片資料夾命名建議

建議資料夾名稱在英文品名（Collection / Type）與「中文顏色」之間保留空格：

  • 推薦命名格式：{COLLECTION} {TYPE} {中文顏色}
  • 範例：PUFF HARNESS 深藍、BLISS LEASH 紅、BLISS LEASH 粉紅、AALTO PET BATHROBE 黑
  • 注意：系統也相容無空格命名（如 BLISS LEASH紅），但建議保留空格以利人工辨識。
  • 階層式資料夾格式（亦支援）：Photo/{COLLECTION}/{TYPE}/{中文顏色}/
  • 例如：Photo/PUFF/HARNESS/深藍/
  • 資料夾內檔案命名建議：
  • 主圖.jpg（商品正面圖，系統會自動縮放並補白邊至 1000×1000）
  • 情境圖1.jpg、情境圖2.jpg（情境展示照）
  • 尺寸規格表.jpg（尺寸說明圖）
  • 背標_M.jpg（背標圖，建議檔名標註尺寸）
