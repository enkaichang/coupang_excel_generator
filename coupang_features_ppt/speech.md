# Slide 1: 封面

各位好，今天為大家介紹的是專為酷澎商品上架打造的自動化工具——「Coupang 報價單與商品圖批次生成系統」。本系統旨在協助營運與上架團隊，以純前端、全自動的方式，在瀏覽器端一鍵完成 Excel 資料解析、品名規格拆解、照片智慧配對，並產出符合酷澎官方規格的標準報價單與合規圖檔。

# Slide 2: 純前端架構：本機執行與資料安全

首先介紹系統的第一大特點：純前端架構與極致資料安全。本系統無需在電腦安裝 Python、Node.js 或任何後端程式，只要使用 Chrome、Edge 等現代瀏覽器即可直接開啟使用。所有 Excel 讀寫與圖片尺寸調整全在電腦本機記憶體完成，反應快速，最重要的是商業報價單、進貨成本與商品原圖完全不上傳任何外部伺服器，確保商業機密不外洩。

# Slide 3: 智慧引擎：品名拆解與圖檔精準配對

第二個特點是我們的智慧解析與配圖引擎。系統能自動自中文品名中辨識出品牌、系列、顏色、尺寸與商品分類；並結合 SKU 代碼、英文系列資料夾名稱與顏色別名，精準搜尋並配對主圖與情境圖。同時內建防呆機制，能有效防止相近顏色（如紅色與粉紅色）誤配，若遇到非標準品名也能智慧從欄位補齊資訊。

# Slide 4: 圖片規格合規與多品類模板管理

第三個特點是圖片自動合規與多品類模板管理。系統會自動將商品主圖與情境圖等比縮放並補上純白底，產出完全符合酷澎官方 1000x1000 正方形規範之圖檔。此外，針對胸背帶、項圈、牽繩等多品類商品，支援獨立綁定專屬 Excel 範本與欄位映射，並 100% 完整保留原報價單之公式、字型與儲存格樣式。

# Slide 5: 雙輸出模式：直覺方便的存檔方式

最後一項特點是靈活的雙輸出模式與設定持久化。使用者可選擇「一鍵存入本機資料夾」，直接透過瀏覽器檔案 API 在本機建立完整的分類目錄與圖檔；亦可選擇「ZIP 壓縮檔下載」一鍵封存所有成果。同時系統支援本機設定持久化與 JSON 備份匯出匯入，讓團隊在不同電腦間也能快速接續作業，大幅提升上架效率。
