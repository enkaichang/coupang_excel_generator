## 🌟 系統特色

1. **純瀏覽器端運作（零安裝、高隱私）**：
   - 無需安裝 Python、Node.js 或任何後端環境，只要有現代瀏覽器（Chrome / Edge / Safari）即可直接執行。
   - 所有 Excel 解析與圖片縮放均在使用者本機記憶體完成，數據不經任何第三方伺服器，安全無外洩疑慮。
2. **完整樣式保留**：
   - 使用 `xlsx-populate` 讀寫 Excel，100% 保留標準報價單模板之所有公式、字型、背景色、框線、凍結窗格與欄寬。
3. **智慧屬性解析與配對**：
   - 自動自中文品名識別品牌、系列、顏色、尺寸與商品分類（胸背帶、牽繩、項圈）。
   - 多層級搜尋引擎：依據 SKU 代碼、系列英文名、顏色別名自動搜尋主圖、情境圖1、情境圖2及背標圖。
4. **圖片規格合規自動化**：
   - 自動檢測圖片寬度，小於 500px 之圖片將自動等比放大並重新編碼，確保符合電商上架規範。
5. **雙輸出模式**：
   - **一鍵存入資料夾 (推薦)**：採用 File System Access API，直接在使用者選定的資料夾內建立完整目錄結構並寫入檔案。
   - **ZIP 壓縮檔下載**：透過 JSZip 打包所有處理完畢之報價單與圖檔。
6. **可視化對照表設定管理器 (Config Modal)**：
   - 視覺化管理來源與目標欄位對照、品類與分類代碼自訂規則、系列中英對照表、顏色別名群組，並支援替換自訂 Excel 模板。

## 🛠 技術架構

- **核心語言**：HTML5, CSS3, Modern JavaScript (ES6+)
- **第三方核心函式庫**：
  - [xlsx-populate (v1.21.0)](https://github.com/dtjohnson/xlsx-populate)：瀏覽器端 Office Open XML 讀寫引擎。
  - [JSZip (v3.10.1)](https://stuk.github.io/jszip/)：瀏覽器端非同步 ZIP 打包與壓縮。
  - [FileSaver.js (v2.0.5)](https://github.com/eligrey/FileSaver.js/)：客戶端檔案下載介面。
- **瀏覽器原生 API**：
  - File System Access API (`window.showDirectoryPicker`)
  - HTML5 Canvas API (圖片縮放與格式轉換)
  - Web Storage API (`localStorage`)

## 🚀 快速開始

1. **開啟程式**：
   - 直接以瀏覽器開啟 `index.html`，或使用 VS Code 的 `Live Server` 擴充套件啟動。
2. **載入檔案**：
   - 將來源 Excel（如 `.xlsx`、`.xls`）拖曳至左側上傳區。
   - 點擊右側上傳區，選取本機之商品照片根目錄（如 `Photo/`）。
3. **設定處理範圍（可選）**：
   - 預設起始列為第 `4` 列。若需分批或測試局部資料，可輸入「結束列」或調整「起始列」。
4. **執行處理**：
   - 點擊「開始處理」，系統將即時更新進度條與診斷統計資訊（成功配對數、缺失圖片警告等）。
5. **匯出成果**：
   - 處理完成後，點擊「**一鍵存入資料夾**」（推薦）選取輸出目錄，或點擊「**打包下載 ZIP**」。

## ⚙️ 功能與操作指引

### 1. 對照表與設定管理器
點擊右上角「**對照表設定**」按鈕，可開啟設定對話框：
- **config.json (欄位對照)**：調整來源 Excel 工作表名稱、標題列、資料起始列、篩選欄位，以及固定/動態欄位映射。
- **品類與分類代碼設定**：自訂來源 `TYPE` 欄位與中文品名關鍵字對應之 Excel 模板、酷澎分類代碼及輸出子資料夾。
- **系列中英對照設定**：管理英文系列資料夾名稱與中文品名系列之對應關係，支援手動新增及一鍵自動掃描。
- **顏色別名設定**：管理顏色別名群組（例如 `WHITE`、`BIANCO`、`白`、`白色`），支援手動維護與自動掃描擴充。
- **模板設定 (Excel)**：上傳並套用自訂的胸背帶或項圈牽繩報價單模板。

### [v1.4.6] - 2026-08-12
#### 🔧 核心修正 (Bug Fixes)
- **修復產生之 Excel 檔案壓縮格式錯誤導致酷澎系統忽略的問題**：
  - 發現系統輸出的 `.xlsx` 檔案容量異常大（約 1.4MB），而經過 Microsoft Excel 儲存後僅約 217KB。經底層分析，確認原因是 `JSZip` 預設使用了 `STORED`（無壓縮）格式來打包 XML，而酷澎後端系統不接受無壓縮的 `.xlsx` 檔案。
  - **解決方案**：在 Excel 最終輸出與打包階段，強制指定 `compression: 'DEFLATE'`，使輸出的 `.xlsx` 檔案結構與標準 Microsoft Excel 完全一致，徹底解決上傳酷澎系統被判定無效或無反應的問題。

- **修復產生之 Excel 缺少 `<dimension>` 標籤的問題 (預防性保留)**：
  - xlsx-populate 輸出時會移除 XML 中的 `<dimension>` 元素。雖然最終確認酷澎上傳系統無反應的主因是模板欄位變更（於 v1.4.4 修復），但缺少 `<dimension>` 仍不符合部分嚴格的 OOXML 規範。

  - **保留原因**：作為額外保護機制保留此變更，確保產生的 Excel 結構更接近原生 Microsoft Excel 存檔的結果。若後續發生其他不可預期的解析錯誤，可隨時從 `app.js` 移除 `patchXlsxDimension` 的呼叫。

## 💡 注意事項與常見問題

1. **瀏覽器相容性**：
   - 推薦使用 **Google Chrome** 或 **Microsoft Edge** 以獲得完整的「一鍵存入資料夾」(File System Access API) 體驗。
   - Firefox 與 Safari 仍可使用「打包下載 ZIP」功能正常匯出。
2. **照片資料夾結構建議**：
   - 建議維持 `Photo/{系列名}/{款式與顏色}/` 之目錄結構，能大幅提高照片自動配對成功率。
3. **本機設定重置**：
   - 若欄位對照或規則產生異常，可開啟「對照表設定」並點擊「**還原為系統預設值**」。
