## 📷 圖片命名最佳實踐規範 (Photo Naming Best Practice)

1. **資料夾命名規範**：`{COLLECTION} {TYPE} {中文顏色}`（在英文品名與中文顏色之間保留空格）。
2. **資料夾內圖檔放置規範**：
   - `主圖.jpg`（商品正面，自動縮放補白邊為 1000×1000 正方形）
   - `情境圖1.jpg`、`情境圖2.jpg`（商品情境照）
   - `size chart_{品名}.png` 或 `尺寸圖.jpg`（尺寸規格表，若為玩偶/無尺寸玩具可留空）
   - `芬蘭_Rukka_附繩款彈力訓練球_綠_one_size_綠_ONE.png` 或 `背標_{尺寸}.jpg`（背標圖檔）

## 🚀 快速測試方式

1. 開啟系統首頁 `index.html`。
2. 點擊「**步驟 1：載入來源商品資料 (Excel)**」，選擇本資料夾內的 `來源商品資料_範例.xlsx`。
3. 點擊「**步驟 2：選取本地商品照片資料夾**」，選擇本資料夾內的 `商品圖庫`。
4. 點擊「**開始比對並批量生成報價單與圖片**」，系統將全自動完成主流與冷門品類（玩具、球、浴袍、雨衣、鞋靴）的 100% 精準匹配！
